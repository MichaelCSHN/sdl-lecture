# AI-Era MSE Experiments Course Outline

状态：active  
日期：2026-06-04  
课程定位：正式课程大纲

## 1. 课程名称

中文名：AI 时代的材料科学实验：从 DOE 到 Self-Driving Labs  
英文名：AI-Era Materials Experiments: From DOE to Self-Driving Labs

## 2. 课程对象

1. 材料、化学、物理、机械、电子等相关专业研究生。
2. 具备一定材料基础和实验基础的高年级本科生。

## 3. 课程核心问题

1. MSE 中的“实验”究竟是什么，为什么它是知识生产核心。
2. 传统实验方法论如何组织实验，优势和边界分别是什么。
3. AI 时代为什么会出现 SDL 这样的闭环实验形态。
4. 哪些实验适合 SDL，哪些并不适合。
5. 如何把一个真实研究问题转写为 SDL 任务。

## 4. 课程主线

课程围绕三条主线展开：

1. `MSE 中的实验`
2. `传统实验方法论：试错法、DOE、硬件与工作流`
3. `AI 时代的 MSE 实验：SDL，包括软件、硬件、数据与闭环决策`

## 5. 课程模块

### 模块 A：实验与 MSE

1. 实验的历史、地位、作用与演变
2. MSE 实验图谱与目录学
3. 实验数据、误差、重复性与不确定度

### 模块 B：传统实验方法论

1. 经验法与试错法
2. DOE 与实验设计
3. MSE 实验硬件、表征链条与实验工作流

### 模块 C：AI 时代的实验

1. SDL 方法论
2. A-Lab 与真实系统分析
3. Case Studio
4. Research Design Studio

## 6. 课程交付模式

### 完整课程模式

1. 作为完整在线课程平台交付。
2. 覆盖理论、案例、方法和研究设计。

### 讲座压缩模式

1. 作为一次 3 小时研究生讲座的压缩版交付。
2. 本质上是完整课程的精选路径，而不是独立产品。

## 7. 课程学习结果

课程结束后，学生应能够：

1. 用“实验中心视角”而不是单纯“材料类别视角”理解 MSE。
2. 区分试错法、DOE 与 SDL 的逻辑差异。
3. 解释一个 SDL 闭环中的参数、观测、推荐和验证。
4. 识别不同类型实验的 SDL 适配度。
5. 为自己的研究问题写出最小 SDL 设计草案。

## 8. 对本项目的含义

本项目首先是该课程的数字课程平台。

因此：

1. 顶层信息架构按课程组织。
2. 讲座模式从课程路径中裁切生成。
3. Background / Foundations 不再是配角，而是课程主干模块。
4. MSE 实验目录学成为课程内核资产之一。
