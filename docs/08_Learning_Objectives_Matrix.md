# Learning Objectives Matrix

状态：active  
日期：2026-06-04

## 1. 学习目标

### LO1

理解实验在 MSE 中的历史角色、知识地位与演变趋势。

### LO2

掌握 MSE 实验图谱与目录学，能够对常见实验进行分类和定义。

### LO3

理解实验中的控制变量、测量变量、误差、重复性与不确定度。

### LO4

区分经验法、试错法、DOE 与 SDL 的方法论差异与适用边界。

### LO5

理解 SDL 闭环中的软件、硬件、数据与决策要素。

### LO6

能够读懂并批判性分析真实 SDL 案例。

### LO7

能够解释案例工作台中的下一实验点推荐逻辑。

### LO8

能够把自己的研究问题转写为最小 SDL 设计草案。

### LO9

能够合理使用 AI 进行知识组织、研究支持与实现辅助。

### LO10

能够审查、质疑并负责任地使用 AI 输出。
