## 二、对话涉及的主要议题与关键洞见

### 2.1 SDL的"盛名之下其实难副"问题

**核心讨论**：A-Lab、GNoME、CAMEO等SDL项目"横空出世"时令人激动，但很快多少有点"盛名之下其实难副"的感觉。

**四重结构性分析**：
- **Goodhart定律**：代理指标异化（A-Lab的Rwp<20%不等于真正的材料发现）
- **杜恒-奎因论题**：表征辅助假设的隐蔽失效
- **物理噪声被低估**：可重复性危机的深层根源
- **评价体系缺失**：缺乏CASP级别的标准化benchmark

**结论**：黎明前黑暗，但黎明形态≠超级AI，而是专门化系统协同。

---

### 2.2 SDL的"大脑"与技术栈

**核心洞见**：GP+BO是SDL大脑的一个器官，不是大脑本身。SDL大脑是四层决策体系：

```
L4：规划/编排层（LLM智能体、强化学习、工作流引擎）
L3：决策策略层（采集函数 EI/UCB/PI/qNEHVI）
L2：代理模型层（GP / GNN / BNN / ML势函数）
L1：表示层（特征工程、图结构、晶体嵌入）
```

**三类技术范式**：
- 统计推断派（GPyTorch + BoTorch）：成熟，A-Lab使用
- 深度学习派（MEGNet, CGCNN, MACE-MP-0）：大数据场景
- 语言模型派（LangChain + ChemCrow + LLaMP）：最新，有幻觉风险

**六个结构性短板**：超出预定义空间失效、只建模相关不建模因果、目标权重无法质疑、非平稳性处理差、冷启动问题、失败结果被系统性丢弃。

---

### 2.3 数据问题

**"反刍"问题的哲学解答**：主动学习倾向推荐"信息量最大"≈"科学上最不确定最有趣"的实验，与科学家直觉对齐——数据生成和科学探索不矛盾。

**五条出路**（按成本-收益排序）：
1. 历史数据系统化（最低成本，立即可做）
2. Sim2Real迁移（Kennedy-O'Hagan框架）
3. 双用途实验设计（科学目标+数据策略同时满足）
4. 联邦数据共享（OPTIMADE标准）
5. 接受"少量数据就能做某些事"的事实

---

### 2.4 SDL硬件的现实

**"三快"约束**：合成快+表征快+分析快，三者均快时SDL效益最大。

**三大硬件瓶颈**（按紧迫程度）：
1. 固体粉末处理（TRL 3-4，最大瓶颈）
2. 高温自动化合成（TRL 4-5，FJH/激光路线最有希望）
3. 表征速度-深度权衡（多模态AI融合是方向）

**2025-2030技术路线图**：
- 液相/薄膜SDL：TRL 8-9（快速成熟）
- 固态无机SDL：TRL 5-6（中期突破）
- 软体机械手/通用SDL：TRL 4-5（长期攻坚）

---

### 2.5 人的席位：六个知识接入口

**核心论点**：人的席位不是需要争取的位置，而是需要精准定位的职责。

**六个接入口**（技术实现路径明确）：
- 接入口I：输入特征空间变换（最低成本，最被忽视）
- 接入口II：GP核函数与超参先验
- 接入口III：硬/软约束函数
- 接入口IV：GP均值函数（物理信息GP，最大科学杠杆）
- 接入口V：采集函数设计（偏好学习BOPE）
- 接入口VI：HITL触发机制（最重要，最不成熟）

**四类不可编码的认识能力**：问题定义、意外结果解读、跨尺度理论整合、价值判断。

---

### 2.6 Vibe Coding的范式意义

**关键洞见**（课程设计的重要转折点）：

Maffettone等人提出的SDL人才培养五类能力（编程、统计/ML、实验设计、领域知识、伦理），是**old school思维**——预设了SDL开发者需要深度懂代码。

Vibe Coding（Karpathy，2025年2月）改变了这一格局：把"编程"和"ML基础"从**入门门槛**变成了**质量上限**。

对课程设计的直接影响：
- 不再需要先教三周Python
- 第一节课就可以直接上手BoTorch
- 评估标准从"能不能写代码"转向"能不能判断输出是否可信"
- PAVE协议：Problem → Ask → Validate → Explain

---

### 2.7 全球课程比较分析

**三类现有课程**：
1. 材料信息学课程（Northwestern, MIT, Skoltech）——计算为主，SDL缺席
2. SDL专项课程（AC多伦多微课程, UMD LEGOLAS）——动手操作，材料深度不足
3. SDL教育框架论文（Maffettone 2023, Snapp & Brown 2023）——描述需求，不提供方案

**LEGOLAS深度剖析**：
- 优点：实物机器人、pH实验可视化GP直觉、符号回归发现Henderson-Hasselbalch方程
- 缺点：材料科学含量极低、一维参数遮蔽高维挑战、开环到闭环跳跃被遮蔽

**Skoltech深度剖析**：
- 优点：seminar为主、论文评述高质量（HW3+Class 10）、全程开源
- 缺点：完全没有SDL、四周太压缩、无实验设计内容

**你的课程的五个差异化优势**：
1. 从"实验可靠性"出发，而不是从"工具怎么用"
2. DOE作为认识论前置，不是过时工具
3. 培养对SDL论文的批判性阅读能力
4. 材料科学专项问题为核心
5. 正面回答"你在SDL里做什么"

## 四、课程设计的核心决策记录

### 决策1：以三个问题组织课程，不以知识模块

```
问题一：你的实验，到底有多可靠？（第1-5周）
问题二：机器是怎么做实验的？（第6-9周）
问题三：你在这里面，究竟做什么？（第10-13周）
```

**理由**：问题比知识点更能驱动真实学习。学生是因为想回答问题而去学习，不是因为学习进度表到了才学习。

### 决策2："教案做给学校看，课程设计做给学生用"

**理由**：学校要求传统课堂教案，但课程实质是案例式、项目式、研究式。两套文本，一套实践。

### 决策3：Vibe Coding作为设计原则，不是工具介绍

**PAVE协议**成为贯穿全课的操作语言：Problem → Ask → Validate → Explain

**理由**：Vibe coding消除了执行层障碍，让判断力得以显现，强化而非削弱课程核心逻辑。

### 决策4：把失败文化显式设计进去

B轨道项目跑失败不扣分，分析失败的深度是评分重点。

**理由**：没有失败文化，学生选最保险的轨道，而不是最有意思的问题。

### 决策5：信封时刻作为学期的闭环

第1周写下"你的实验有多可靠（1-10分）"封存，第13周打开对比。

**理由**：这是最真实的课程效果评估，也是最有力的情感设计。

### 决策6：开源社区三层结构

```
第一层：课程内部（GitHub私有仓库）
第二层：代际传承（优秀作品存档课程网站，下届参考）
第三层：学科社区（贡献到awesome-sdl等）
```

## 六、一句话总结

这门课从"你的实验，到底有多可靠"出发，经由"机器是怎么做实验的"的探索，到达"你在这里面，究竟做什么"的自我定位——不是教SDL工具，而是在AI深度重塑科学研究的时刻，帮助材料科学家认识自己、定位自己、进化自己。

> "这门课的终极测试不是期末考试，而是学期结束一年后，你是否在做和一年前不同的事，以及你是否知道为什么不同。"
